# Run 011 - 22 Mar 2026, 05:09

## Goal
Prepare `frontend` and `backend` to work cleanly as standalone repositories after subtree push.

## Changes Applied
Added folder-level `.gitignore` files:
- `frontend/.gitignore`
- `backend/.gitignore`

Added short folder-level README files:
- `frontend/README.md`
- `backend/README.md`

## Why This Was Needed
When `frontend` and `backend` are pushed to separate repos, root-level `.gitignore` is not included there.
Without local `.gitignore` files, generated files like `node_modules`, build output, logs, and local env files can be committed by mistake.

README files were added so each split repo has basic run/build/env instructions without depending on root docs.

## Result
- Frontend split repo now has its own ignore policy and starter README.
- Backend split repo now has its own ignore policy and starter README.
- Three-repo workflow remains compatible with existing subtree push script.
