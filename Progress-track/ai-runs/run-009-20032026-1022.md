## API Endpoints Used by Frontend
- `GET /hr/staff` (paginated) — staff directory
- `GET /hr/staff/:id` — staff detail
- `GET /hr/staff/:id/profile` — staff profile tab
- `GET /hr/staff/:id/leave-allocations` — leave allocation tab
- `POST /hr/staff` — add staff (slide-over)
- `GET /hr/departments` — settings page + slide-over
- `GET /hr/designations` — settings page + slide-over
- `POST /hr/departments` — create department
- `DELETE /hr/departments/:id` — deactivate department
- `POST /hr/designations` — create designation
- `GET /hr/leave-types` — settings page
- `POST /hr/leave-types` — create leave type
- `GET /hr/leave-requests` (paginated) — leave management
- `POST /hr/leave-requests/:id/approve` — approve leave
- `POST /hr/leave-requests/:id/reject` — reject leave
- `GET /hr/attendance` (paginated) — attendance page (existing records)
- `GET /hr/staff?filter[status]=active` — attendance page (active staff list)
- `POST /hr/attendance/bulk-mark` — save attendance
