## Key Design Decisions Documented
- LLM uses user's own JWT — PBAC enforced automatically, zero new permission logic
- Phase 8A (Assistant): Cloud API via Replit AI proxy (OpenAI/Anthropic); Phase 8B (Copilot): same, with future hybrid self-hosted router
- AI credits in subscription plans (Basic: none, Standard: 500K tokens/month, Enterprise: 5M tokens/month)
- Confirmation levels: 0=auto (reads), 1=single button (single writes), 2=type CONFIRM (bulk/irreversible)
- Permanent blocklist: academic year delete, bulk student delete, user role changes, all /platform/* endpoints
- Async job tracking via SSE polling + Redis state persistence if connection drops
- FAQ cache pre-warmer: 6 common query types cached at session start — zero LLM tokens for most common parent queries
- PII filter layer: strips Aadhar, bank details, health records before LLM context injection
- Rate limits: 10 writes/hour, 3 bulk ops/day per user — Redis TTL counters
- Offline: AI section hidden cleanly; slow connection: streaming disabled, 120s timeout, 4K context limit
