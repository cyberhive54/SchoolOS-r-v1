# SchoolOS Frontend

This folder contains the SchoolOS Next.js frontend app.

## What this is
- Framework: Next.js (App Router)
- Language: TypeScript
- Package manager: pnpm

## Local run
```bash
pnpm install
pnpm dev
```

## Build and start
```bash
pnpm build
pnpm start
```

## Environment
Copy `.env.example` to `.env.local` (or set env vars in your hosting panel) and update values.

For full deployment steps, see `DEPLOYMENT.md`.
