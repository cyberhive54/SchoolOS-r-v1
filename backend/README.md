# SchoolOS Backend

This folder contains the SchoolOS NestJS backend API.

## What this is
- Framework: NestJS
- Language: TypeScript
- Package manager: pnpm

## Local run
```bash
pnpm install
pnpm start:dev
```

## Build and start
```bash
pnpm build
pnpm start:prod
```

## Environment
Copy `.env.example` to `.env` and fill all required values before running.

For Docker and production setup, see `DEPLOYMENT.md`.
